The final 13 native explorer checks cover packaged startup, Settings/native version consistency, permission denial, all 17 regions, inspection, camera controls, quality/explosion, fullscreen/Escape, four renderer entry/exit cycles, offline navigation, actual context loss, request restrictions and absence of an external browser launch. The 9 new native checks cover CPU installation/occupancy, two distinct DIMMs, selected M.2 slot and totals, incoming schema-version rejection without mutation, restart restoration, explicit replacement, removal, reset confirmation/cancellation, empty state after a second restart, catalog preservation and page errors.

Automated restart tests await an atomic SQLite save, terminate the runner-owned native process, and launch a fresh process. This verifies persistence across process exit, including an abrupt exit; it does not claim execution of a normal Windows Close-button action. The native app was also opened and observed through Computer Use with the assembled fixture build. Active user input prevented an automated native-frame close. The process later exited normally (exit 0, no termination signal) while under user control. After the final package was installed, a normal launch showed the native Home and version 0.3.0; the window was closed again before Builder input completed. A read-only SQLite connection and the domain validator confirmed the user’s reset build remained valid and empty. Normal-size restoration passed in an earlier native run; that conditional comparison was skipped in the final run because the saved window was maximized. User interaction with the live demo is outside the automated test record.

Renderer tests inspect actual scene-group positions for CPU, DIMM A2 and M.2 slot 02, then perform eight install/remove cycles per browser. Final geometry/material/texture counts and live GPU buffer/texture counts equal their baseline, transition state clears, and stationary GPU clears stay at two or fewer over the idle measurement window. Pure animation tests additionally repeat 100 cycles and verify previews, reversed removal, explosion offsets and reduced motion.

Resource measurements hold quality at Low to keep one WebGL context. The first attempt counted internal default textures across adaptive context replacement; the corrected test compares resources within one context. Existing adaptive quality and context/renderer lifecycle checks remain intact. An initial native run overlapped Playwright and correctly detected those new Chromium processes in its external-browser assertion; the final installed-native run was isolated and all 22 checks passed. Production preview initially crossed the sandbox network boundary; running its server and browser in the same execution context resolved that test-environment issue.
